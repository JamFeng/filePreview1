# 本地文件在线预览应用（Vue3 + Vite + TS + Pinia）

## 项目定位

纯前端**静态网页应用**，无后端、无服务端依赖，实现**本地文件在线预览工具**，用户上传本地文件即可直接预览，支持电脑端 + 移动端。

---

## 一、核心技术栈（必须严格遵守）

- 框架：**Vue 3 + 组合式 API (＜script setup＞)**
- 构建工具：**Vite**
- 语言：**TypeScript**
- 状态管理：**Pinia**
- 样式：**CSS3 / SCSS**、扁平化风格、无冗余 UI 框架
- 允许使用成熟开源预览插件：pdfjs-dist、office-viewer、exceljs、canvas 相关预览库

---

## 二、页面结构（单页应用）

1. **顶部导航栏**
  - 应用名称、简洁图标、主题风格标识
2. **上传区域（核心）**
  - 支持**点击上传 + 拖拽上传**
  - 支持**多文件同时上传**
  - 上传状态提示、文件大小/格式限制提示
3. **文件列表区域**
  - 展示已上传文件名称、类型、大小、操作按钮
  - 支持：预览、删除、清空全部
4. **预览弹窗 / 预览区域**
  - 全屏/大窗口预览
  - 支持关闭、缩放、重置、翻页（文档类）
5. **底部信息栏**
  - 版权、说明、支持格式

---

## 三、功能需求（必须实现）

### 1. 文件上传

- 支持多选文件上传
- 拖拽上传（高亮拖拽区域）
- 文件格式校验、文件大小限制
- 上传成功/失败提示
- 重复文件提示
- 清空所有文件 / 单个删除

### 2. 文件在线预览（必须支持）

- **图片**：jpg、jpeg、png、gif、bmp、webp（支持缩放）
- **PDF**：支持翻页、缩放
- **TXT / 文本文件**：正常展示文字、自动换行
- **Excel**：表格展示、简单预览
- **Word**：文本内容预览

### 3. 预览操作功能

- 放大 / 缩小
- 恢复默认尺寸
- 关闭预览
- PDF/多页文件支持上一页、下一页
- 适配屏幕自动最佳显示

### 4. 响应式布局

- PC 端：正常布局
- 平板 / 移动端：自动适配、按钮变大、弹窗全屏化
- 所有弹窗、预览区支持手势缩放（移动端）

---
